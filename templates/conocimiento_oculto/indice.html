Síntesis de los principales hallazgos

    {% if s %}
  1. Supervisado. Predecir si un municipio tendrá pérdida de bosque «alta» (≥ {{ s.umbral_alta_ha|n }} ha) con su historial: el modelo elegido ({{ s.elegido }}) logra exactitud {{ (s.modelos[s.elegido].accuracy*100)|n(1) }} %, F1 {{ s.modelos[s.elegido].f1|n(2) }} y AUC {{ s.modelos[s.elegido].auc|n(2) }} en 2019–2024. Pero una regla simple («Alta si lo fue el año anterior») rinde igual ({{ (s.baseline_persistencia.accuracy*100)|n(1) }} %): lo que se descubre es que la pérdida es muy persistente.
    2. {% endif %} {% if c %}
  2. Clustering. Los {{ c.n_municipios|n }} municipios se agrupan en {{ c.k_elegido }} perfiles; el de mayor pérdida ({{ c.perfil[0].municipios }} municipios, {{ (c.perfil[0].pct*100)|n(1) }} %) suma el {{ (c.perfil[0].pct_perdida_total*100)|n(0) }} % de la pérdida media anual y reúne a los frentes de la Amazonía (San Vicente del Caguán, La Macarena, Cartagena del Chairá…).

No representan a la población.

Cómo reproducir el trabajo

  • Datos para Orange: conocimiento_oculto/datos/ (se regeneran con python conocimiento_oculto/preparar_datos_orange.py deforestacion_limpio.csv).
  • Flujo de Orange: conocimiento_oculto/conocimiento_oculto.ows (con los scripts de orange_scripts/) y guía paso a paso en orange/GUIA_FLUJOS_ORANGE.md.
  • Extracción de comentarios: conocimiento_oculto/extraer_comentarios_youtube.py y datos en conocimiento_oculto/youtube/ (la clave de la API nunca se publica).
  • Verificación en Python: python conocimiento_oculto/referencia.py.
